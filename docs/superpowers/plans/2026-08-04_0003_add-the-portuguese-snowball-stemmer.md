# #3 Portuguese Snowball stemmer — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `PortugueseSnowballStemmer.Stem(word)` reproduces `nltk.stem.snowball.SnowballStemmer("portuguese")` on every word of a frozen corpus, as an original implementation of the published Snowball algorithm.

**Architecture:** A standalone `public static class` beside English, French and Spanish — the fourth copy of the region machinery, and the last one before #44 extracts it. Nasal vowels are expanded to a vowel-plus-tilde pair for the duration of the run so the tilde behaves as a consonant; acute accents are **kept**, unlike Spanish. A new `generate_oracles.py` section freezes the reference values into `tests/oracles/snowball_pt.json`.

**Tech Stack:** C# (net10.0 + netstandard2.0), xunit, Python 3 with `nltk` for oracle generation only.

**Spec:** `2026-08-04_0003_add-the-portuguese-snowball-stemmer.md` (in `../specs/`).

### Task 2: The stemmer

**Files:**

- Create: `src/DataNet.Text/Stemming/PortugueseSnowballStemmer.cs`

**Depends on:** Task 1.
**Produces:** the implementation.

- [x] **Step 1: Nasal expansion on entry, restoration on exit**

`ã` → `a~`, `õ` → `o~` before regions are computed; the inverse as the last act.
Comment the reason in one line: the tilde must not count as a vowel, or R1/R2
close too early.

- [x] **Step 2: Regions RV, R1, R2**

Portuguese uses the same three-branch RV rule as Spanish. This is the one part
that may legitimately resemble the Spanish file.

- [x] **Step 3: Step 1 — standard suffix removal, longest match across groups**

Include **`ança` / `anças` in the delete-if-in-R2 group** (D3). Without it,
`esperança` falls through to the residual step and the `ç` → `c` rule and comes
out as `esperanc` — a word-shaped answer that no reviewer would flag.

- [x] **Step 4: Step 2 — verb suffixes, with fall-through**

When the longest matching suffix is rejected because it lies outside RV, **continue
the search** with the next-longest. Write the loop so this is structural, not an
extra `if`: `amáveis` needs `eis` after `áveis` is rejected.

- [x] **Step 5: Steps 3, 4, 5 and the residual rules**

Including `ç` → `c`. Note that the trailing `o` of `geração` is removed here, as a
residual suffix — not as part of the nasal handling.

- [x] **Step 6: No final accent-stripping step**

There is none. If a reader of the Spanish file added one out of symmetry, `país`
would stem to `pais` and several other cases would move with it. Add a comment
saying the absence is deliberate.

- [x] **Step 7: Both targets compile**

```bash
build_all
```

Suppress CA1845 with the same reason and wording as the English, French and
Spanish stemmers: the span-based `string.Concat` overload is net-only, and the
`Substring` form is what compiles for netstandard2.0.
