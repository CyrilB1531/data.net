# MannWhitney

The Mann-Whitney *U* test: do two independent samples come from one distribution?

The rank-based counterpart to [`TTest.Independent`](ttest-independent.md): it assumes nothing
about the shape of either distribution, only that a value from one can be compared with a value
from the other.

## Members

| Member | What it does |
| --- | --- |
| [`MannWhitney.Test`](mannwhitney-test.md) | Compares two independent samples by their ranks. |
