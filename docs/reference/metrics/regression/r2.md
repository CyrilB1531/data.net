# R2

The coefficient of determination: how much better the model is than always predicting the mean,
as a unitless score.

## Members

| Member | What it does |
| --- | --- |
| [`R2.Score`](r2-score.md) | One score for the whole prediction: `1` minus the residual variance over the truth's variance. |
| [`R2.PerOutput`](r2-peroutput.md) | One score per output, unreduced. |
| [`R2.VarianceWeighted`](r2-varianceweighted.md) | One score, each output counted in proportion to how much its own truth varies. |
