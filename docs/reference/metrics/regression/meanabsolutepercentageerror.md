# MeanAbsolutePercentageError

The miss as a fraction of the truth, for targets whose scale changes from sample to sample.

## Members

| Member | What it does |
| --- | --- |
| [`MeanAbsolutePercentageError.Score`](meanabsolutepercentageerror-score.md) | The mean of `\|yTrue - yPred\| / \|yTrue\|`, with the denominator clamped away from zero. |
| [`MeanAbsolutePercentageError.PerOutput`](meanabsolutepercentageerror-peroutput.md) | One mean absolute percentage error per output, unreduced. |
