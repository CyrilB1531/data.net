# RootMeanSquaredError

`MeanSquaredError` with the square root taken, which puts it back into the target's units — the
version to show a human.

## Members

| Member | What it does |
| --- | --- |
| [`RootMeanSquaredError.Score`](rootmeansquarederror-score.md) | The square root of the mean squared error, taken per output before the outputs are reduced. |
| [`RootMeanSquaredError.PerOutput`](rootmeansquarederror-peroutput.md) | One root mean squared error per output, unreduced. |
