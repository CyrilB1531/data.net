# PinballLoss

The loss for a model that predicts a quantile rather than a mean: over- and under-shooting are
charged different rates.

## Members

| Member | What it does |
| --- | --- |
| [`PinballLoss.Score`](pinballloss-score.md) | The mean pinball loss at the quantile `alpha`. |
| [`PinballLoss.PerOutput`](pinballloss-peroutput.md) | One pinball loss per output, unreduced. |
