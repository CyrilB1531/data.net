# Precision

Of everything the model flagged as a class, how much really belonged there — the metric for the
cost
of a false alarm.

## Members

| Member | What it does |
| --- | --- |
| [`Precision.Score`](precision-score.md) | True positives over everything predicted into the class, reduced to one number by `average`. |
| [`Precision.PerClass`](precision-perclass.md) | Precision for every class, in label order. |
