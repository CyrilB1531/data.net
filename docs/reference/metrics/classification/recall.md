# Recall

Of everything that belonged to a class, how much the model found — the metric for the cost of a
miss.

## Members

| Member | What it does |
| --- | --- |
| [`Recall.Score`](recall-score.md) | True positives over the true size of the class, reduced to one number by `average`. |
| [`Recall.PerClass`](recall-perclass.md) | Recall for every class, in label order. |
