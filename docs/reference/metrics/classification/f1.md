# F1

Precision and recall in one number, weighted equally — the default report for a class you care
about.

## Members

| Member | What it does |
| --- | --- |
| [`F1.Score`](f1-score.md) | The harmonic mean of precision and recall, reduced to one number by `average`. |
| [`F1.PerClass`](f1-perclass.md) | F1 for every class, in label order. |
