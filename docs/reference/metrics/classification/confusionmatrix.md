# ConfusionMatrix

Predictions counted against truth, one cell per (true, predicted) pair — the object every other
metric on this page is a division of.

## Members

| Member | What it does |
| --- | --- |
| [`ConfusionMatrix.Compute`](confusionmatrix-compute.md) | Counts the samples into a table whose rows are true labels and whose columns are predicted ones. |
| [`ConfusionMatrix.ToArray`](confusionmatrix-toarray.md) | Copies the cells into a rectangular array, raw or scaled. |
