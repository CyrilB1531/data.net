# VMeasure

The single number to report when you must report one, and the one to distrust when it disagrees with `AdjustedRand` — that gap is chance correction, and it usually means the clustering has invented clusters.

## Members

| Member | What it does |
| --- | --- |
| [`VMeasure.Score`](vmeasure-score.md) | Homogeneity and completeness as one number, their harmonic mean. |
